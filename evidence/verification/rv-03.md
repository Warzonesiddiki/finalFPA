## 5. Undeclared Changed File Guard (`team.py check`)

### Injected State:
Claim window edits files under scope, but handoff `## Changed` omits one of them (e.g. `touched` has `rules_01_08.py` and `rules_09_16.py`, but `declared` only lists `rules_01_08.py`).
`scripts/team.py` lines 1026–1030 inspect:
```python
undeclared = [w for w in touched if w not in declared]
if undeclared:
    (fails if args.strict else warns).append(
        f"{f.name}: {len(undeclared)} file(s) changed inside the claim window but not declared under '## Changed': {', '.join(undeclared[:6])}"
    )
```
### Execution Result:
- In default mode (`strict=False`): appends to `warns`.
- In strict mode (`strict=True` via `team.py check --strict`): appends to `fails`.
```
Undeclared caught in warns (strict=False): ['HO-test.md: 1 file(s) changed inside the claim window but not declared under Changed: app/engine/rules/rules_09_16.py']
Undeclared caught in fails (strict=True): ['HO-test.md: 1 file(s) changed inside the claim window but not declared under Changed: app/engine/rules/rules_09_16.py']
```
### Verdict:
**FALSIFIABLE.** Caught as a warning in standard check and as a hard failure in `--strict` mode.

## Summary & Finding on Rule Strictness
- **All 5 targeted rules CAN be made to fail.**
- **Nuance found:** Rule #5 (undeclared changed file) emits a `WARN` rather than a `FAIL` in default `team.py check` unless `--strict` is passed. This allows flexibility during working draft iterations, but enforces hard blocking when `--strict` is enabled.
